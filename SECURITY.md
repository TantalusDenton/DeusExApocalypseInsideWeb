# Security policy

The public website is static and has no login, registration, or user-submission endpoints.

To report a security issue, use GitHub's private vulnerability reporting for this repository when available. Do not post credentials, tokens, or personal data in a public issue.

The site is built and deployed by GitHub Actions using repository- and environment-scoped AWS OIDC roles. Report issues in the CI/CD or CloudFormation configuration through the same private reporting channel.
